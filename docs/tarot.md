# 塔罗 · v3.5

## 用户流程

封面进入塔罗 → 登录 → 填写问题、选择牌阵与正逆位 → 洗牌 → 点选牌背 → 确认揭牌 → 解读整组牌 → 自由追问。无需紫微命盘、生日、用户模型 Key。系统管理员进入原后台管理模型和用户。

78 张完整牌组，支持一张指引（1）、看清当下（3）、两种选择（5）和关系之镜（5）。桌面与手机均可选牌，支持减少动态效果的系统偏好。已有记录可从历史恢复。洗牌时在后台使用 `crypto.randomInt` 的 Fisher–Yates 算法；不会重复抽中同一张牌。界面在揭牌前不知道隐藏牌序，确认结果后不允许修改。

创建牌组使用客户端请求 UUID 去重；揭牌用数据库行锁保存，重复请求返回同一结果，不同结果冲突返回 409。未揭牌不能启动 AI 解读。对话使用现有持久化任务、服务端凭据、用户次数与 Token 预留、全站模型额度和账本。每次提交解读或追问与紫微解读共用次数，抽牌不调用模型。解读下方「记住的事」可确认待保存内容或忘记已保存内容，与紫微共用。塔罗工具仅开放查找记忆与提议待确认记忆，不开放紫微工具或由模型决定抽牌。

## 开源参考与牌面

参考 [anois/tarot](https://github.com/anois/tarot) 的完整牌组、洗牌及选牌交互思路。页面和后端按观星现有结构实现，不引入其客户端 Key 流程。中文牌义采用该仓库 `src/deck/data/card-meanings-zh.json`（2026-11-05 获取）；上游声明应用为 MIT、基础牌数据源于 CC0 Tarot JSON，中文补充保留上游 [MIT 许可与版权声明](licenses/anois-tarot-MIT.txt)。

牌图独立来自 Wikimedia Commons 的 1909 原版扫描，逐张来源、Public domain 标示与校验值见 [sources.json](../public/assets/tarot/sources.json)。未采用参考项目中许可不明确的牌图；未调用付费生图或收费模型进行测试。原版公有领域说明不覆盖现代重绘/新扫描的新增权利，后续换图需重新核对来源。

## 部署与升级

沿用现有 Docker 与 PostgreSQL/pgvector，无新增服务，无本地模型。仅增加可空 `sessions.tarot JSONB` 字段，旧会话保持可读；启动时自动迁移。只需按 [服务器部署指南](server-deployment.md) 替换 v3.5.0 离线包并执行 `./scripts/install-offline.sh`。保留 `.env.server`、数据库与证书卷。已有管理员模型和用户限额直接生效。

入口为 `/#tarot`，记录地址为 `/#tarot/<会话 UUID>`；访问他人的 UUID 会返回 404。静态 GitHub Pages 和旧单用户工作台只给出服务器入口，不提供假解读。

## 验证

`tests/tarot.test.ts` 验证 78 张牌与资源校验、无放回抽牌、正逆位、输入校验、固定结果、重复请求与并发揭牌、账号隔离、隐藏牌序不外泄、未揭牌禁止调用、站点凭据、整组上下文、追问、与紫微共用次数及 Token 上限、用量账本。集成测试使用本地模拟服务，无收费调用。
