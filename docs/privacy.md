# 数据流与隐私

观星提供公开静态体验和完整本地 Agent 工作区。二者的数据持久化方式不同，下面分别说明。

## 公开静态页面与排盘

网页托管方会收到正常页面及静态资源请求，其基础设施可能记录 IP 地址和请求信息。出生日期、时辰、性别与称呼在当前浏览器中用于排盘，不随静态资源请求主动上传。静态版不提供业务数据库或持久化历史命盘。

只有主动点击 AI 解读，浏览器才向用户填写的模型服务发送十二宫及星曜结构、所填问题、模型名、系统提示和认证 Key。结构化命盘请求不附带称呼、完整出生日期、农历日期或年龄；但命盘与问题仍可能透露个人信息，不属于匿名数据。

浏览器直接调用要求服务提供相应 CORS 权限。请求失败不会自动改投其他服务。

## 本地 Agent 工作区

Docker 本地版由 Node.js 后端提供同源 API，PostgreSQL 保存：

- 会话、用户主动附带的命盘输入，以及用户/助手消息。
- 模型配置、价格、预算、运行状态、工具活动和逐次调用用量。
- 记忆内容、所属范围、待确认/已确认状态及预留的向量字段。
- 管理员密码散列和登录会话的散列信息。

数据位于本机 Docker 具名卷，重启容器不会清除。页面使用 HttpOnly 登录会话，不以模型 Key 代替管理员认证。应用默认仅映射到 `127.0.0.1`，数据库没有宿主机端口。

发送 Agent 问题时，浏览器将问题、选定模型和临时 Key 交给自己的本地后端，后端再请求所选模型服务。模型上下文可能包含最近对话、相关已确认记忆、问题和工具返回的命盘数据。虽然命盘工具使用字段清单排除原始称呼和完整生日，用户自己在聊天或记忆中写入的信息仍可能进入模型上下文。

## API Key

Key 只用于当前页面及本次服务端请求的内存，不写入 localStorage、Cookie、URL、模型配置或数据库，刷新或关闭页面后需重新输入。

静态版通过请求头直接发送给所选服务；本地版先交给同源后端再转发给所选服务。请确认服务地址可信。远程模型地址要求 HTTPS，本机地址可使用 HTTP。本地后端另外限制目标主机，新增网关需要管理员配置 `MODEL_ALLOWED_HOSTS`。

本项目不提供共享 Key，不自动配置模型服务，也不会下载本地模型。费用、数据保存与训练政策以用户选择的服务为准。

## 记忆确认与向量状态

模型只能提出待确认记忆，用户确认后才作为长期信息使用。用户可以手动添加、编辑和删除记忆。编辑正文会使旧向量失效，避免旧索引代表新内容。

目前没有配置 embedding provider，应用不会为记忆调用向量模型。检索使用文本匹配和近期已确认记忆；pgvector 存储及检索路径已预留，但不能据此声称默认提供语义检索。未来接入向量服务时，需要同时说明哪些文本会发往该服务。

## 删除与导出

删除会话会删除其消息、运行和会话范围的记忆。全局记忆需要单独删除。用量账本保留并解除会话关联，防止删除会话重置预算。

业务 JSON 导出不包含密码散列、登录令牌或临时 Key。它仍包含对话和记忆，应保存在自己的设备。删除应用内数据不会自动删除用户此前制作的导出或数据库备份，也不会删除模型服务商已收到的数据。

备份与数据卷说明见 [本地部署](local-deployment.md)。

## 解读内容

紫微斗数和 AI 文字是传统文化与自我反思材料，可能有误，不构成科学预测。不要在问题里填写身份证号、联系方式、密码或其他不必要的个人信息。不要把模型的命理推断当成已确认的个人事实。
