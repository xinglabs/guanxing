# 数据流与隐私

观星 V3 有三种运行方式。公开部署的服务器版会保存账号和对话，不能沿用静态页面“只在浏览器中使用”的说明。

| 运行方式                | 模型 Key                                     | 数据保存位置                                 |
| ----------------------- | -------------------------------------------- | -------------------------------------------- |
| GitHub Pages 等静态页面 | 访客临时填写，浏览器直接调用所选服务         | 不提供业务数据库；排盘输入保留在当前页面内存 |
| 本地完整工作区          | 使用者临时填写，经自己的后端转发             | 本机 PostgreSQL，单管理员工作区              |
| 独立网站服务器版        | 管理员配置站点 Key，服务器加密保存并代为调用 | 站点 PostgreSQL，按用户账号隔离              |

## 页面访问与排盘

网页托管方会收到页面及静态资源请求，其基础设施可能记录 IP 地址和请求信息。出生日期、时辰、性别与称呼在浏览器中用于排盘，不随静态资源请求主动上传。

静态版只有在用户主动发送问题时，才向所填模型服务发送十二宫及星曜结构、问题、最近对话、模型名、系统提示和认证 Key。结构化命盘请求使用字段清单排除称呼、完整出生日期、农历日期和年龄；用户主动在聊天中填写的信息仍会发送。浏览器直连需要模型服务允许 CORS，请求失败不会自动改投其他服务。

本地和服务器版要求先登录。用户确认排盘时，完整出生输入与关联的命盘会保存到用户自己的会话中，表单会说明保存行为；不必先发送问题，刷新和重新登录即可恢复。确认排盘本身不会请求模型。打开历史解读会恢复它原本关联的命盘。静态演示版仍只在当前页面排盘，不提供账号存储。

## 账号与持久化数据

本地和服务器版使用 PostgreSQL 保存：

- 会话、发送问题时关联的命盘输入、用户和助手消息。
- 运行状态、工具活动、逐次模型调用用量。
- 记忆正文、所属范围、待确认或已确认状态，以及可选向量字段。
- 模型服务地址、模型名称、管理员填写的价格与预算。
- 密码散列和登录会话的散列值，不保存明文登录密码。

服务器版另外保存用户名、账号角色、停用状态、注册时间、站点设置、后台任务和加密的模型凭据。任务记录包含提交的问题、请求标识、处理状态和完成结果，便于关闭页面后继续查看。

登录使用 HttpOnly、SameSite=Strict 会话 Cookie；HTTPS 登录会附带 Secure 标记。页面会用 sessionStorage 记住当前账号最后选中的会话 ID，不在其中保存模型 Key 或聊天正文。数据卷在容器重启后仍保留。

服务器版首次创建管理员需要部署配置中的初始化口令，默认关闭新用户注册。管理员可以开放或关闭注册、调整每日任务次数、停用账号和重置密码。账号停用或密码重置会撤销旧登录；用户自己修改密码后，会重新建立当前登录。

## 用户隔离与运营者权限

服务器版的会话、消息、运行、任务、记忆、检索、用量和导出均按当前登录用户限定范围。普通用户不能通过更换记录 ID 读取其他账号的数据。跨会话记忆也只属于该用户，不是全站共享记忆。

管理接口提供账号管理和全站用量统计，不提供直接浏览其他用户聊天、命盘或记忆的入口。管理员仍可以重置账号密码，服务器或数据库管理者也能访问数据库和备份。因此，这是应用层的账号隔离，**不是对站点运营者的端到端加密或保密承诺**。聊天和记忆正文目前不做应用层加密。

## 模型 Key 的处理

### 静态版和本地工作区

访客或使用者填写的临时 Key 只用于当前页面和本次请求的内存，不写入 localStorage、Cookie、URL、模型配置或数据库。刷新或关闭页面后需重新输入。

静态版直接发送给所选模型服务；本地版先交给同源后端，再转发给所选服务。远程服务要求 HTTPS，允许的本机地址可使用 HTTP。后端限制模型目标主机；新增网关需配置 `MODEL_ALLOWED_HOSTS`。

### 服务器版

普通用户无需提供 Key。管理员在模型管理页填写或更换站点密钥，保存后不会再回显明文。服务器使用 **AES-256-GCM** 加密，密文与模型 ID 绑定后写入 `model_credentials`；主密钥 `APP_SECRET` 保留在服务器部署配置中，不写入数据库。执行任务时才在服务器内存中解密并请求模型服务。

模型列表、业务导出、用量账本和任务记录均不包含 Key 明文或加密凭据。此措施主要保护单独泄漏的数据库副本；同时拥有服务器配置和数据库的人仍可能解密凭据。备份与恢复必须保留原 `APP_SECRET`，不能随意重新生成；丢失后需重新配置模型 Key。

项目不会自动申请模型账号、充值、启动或下载本地模型。模型费用、内容保存与训练政策以所选服务为准。

## 发往模型的内容

本地和服务器版的 Agent 上下文可能包含当前问题、最近对话、相关已确认记忆、系统规则和工具返回的命盘结构。命盘工具排除原始称呼和完整生日，但用户自己在问题、聊天或记忆里填写的内容仍可能发给模型服务。

服务器版由管理员选择模型服务，普通用户无法修改模型网关或获取站点 Key。所有模型调用都经站点后端发生。

## 记忆确认与向量状态

模型提出的记忆先进入待确认状态，确认后才用于长期记忆检索。用户可以在「我的账号 → 记住的事」确认或删除。底层 API 仍支持手动添加和编辑；编辑正文会使旧向量失效。

目前没有接入 embedding provider，也不会为记忆调用向量模型。实际检索使用文本匹配和近期已确认记忆；pgvector 的 768 维存储与检索路径已实现，但默认不提供语义检索。以后接入向量服务时，需要说明将向该服务发送哪些文本。

删除一条长期记忆不会改写以前的聊天或已经生成的任务结果；如果相同内容存在于最近对话中，它仍可能作为聊天上下文出现。需要清除相关聊天时，应一并删除对应会话。

## 后台任务与使用额度

本地工作区的运行与当前请求绑定，停止或断开页面连接会尝试取消模型请求。服务器版使用持久化任务：提交成功后，关闭、刷新页面或退出登录不会取消任务。用户可明确点击停止；已经发送到模型服务的调用仍可能产生费用。

服务器版按每日提交次数控制个人额度，失败和停止的已提交任务也计入次数。同一账号同时只能有一个排队或运行中的任务。模型另有全站每日 token 上限和可选费用上限。账本中的预留、估算或未知值不等于服务商确认的实际消耗。

进程重启后，尚未开始的排队任务会继续处理；被中断的运行标记为失败或已取消，不会自动重复请求模型。

## 删除、导出与备份

删除会话前需要先停止其中的任务。删除会话会删除对应的消息、运行和会话范围记忆；跨会话记忆需要单独删除。

为了避免删除数据重置使用额度，调用账本会保留并解除会话关联。服务器版还会保留已提交任务的编号、状态、时间等计数记录，同时清除该会话任务中保存的问题正文和结果。当天次数不会因删除会话恢复。

业务 JSON 导出包含该账号的会话、消息、运行、记忆和用量，不包含密码散列、登录令牌、模型 Key 或加密凭据。导出的文件仍包含个人信息，应妥善保存。应用内删除不会同步删除之前制作的导出、数据库备份或模型服务商已经收到的数据。

备份和部署方式见 [本地部署](local-deployment.md) 与 [服务器部署](server-deployment.md)。服务器配置文件、数据库备份均应限制访问，不要上传到公开 GitHub 仓库。

## 内容与当前服务范围

解读由 AI 生成，基于传统文化资料作出推论，可能有误，不构成科学预测。不要把模型推断自动视为已确认的个人事实，也不要填写身份证号、密码或其他不必要的敏感信息。

当前版本不包含收费、打赏、充值、订单或支付功能。
