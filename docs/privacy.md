# 数据流与隐私

观星是静态网页应用。排盘在浏览器中运行，项目没有接收出生信息的业务后端。

## 打开网页与排盘

网页托管方会收到正常的页面与静态资源请求，其基础设施可能记录 IP 地址和请求信息。出生日期、时辰、性别与称呼在当前页面内用于排盘，不随静态资源请求主动上传。

## 主动请求 AI 解读

只有点击解读操作后，浏览器才向你填写的服务地址发送请求。发送内容包括：

- 十二宫名称、地支位置、命宫与身宫标记。
- 各宫星曜名称、类型、亮度和四化信息。
- 你填写的问题，以及指导模型如何解读的系统提示。
- 请求模型名与作为认证凭据的 API Key。

应用通过明确字段清单构建请求，不附带称呼、完整出生日期、农历日期或年龄。但命盘和问题仍可能透露个人信息，不能将其理解为匿名数据。第三方模型服务还会看到连接它所需的网络信息；其保存、训练、费用与删除规则以该服务的政策为准。

## API Key

Key 只保留在当前页面内存中，刷新或关闭页面后需要重新输入，不写入 localStorage、Cookie 或 URL。Key 通过请求头直接发送给所选服务；请确认服务地址可信。应用要求远程地址使用 HTTPS，本机 localhost 可使用 HTTP。

本项目不提供共享 Key，也不经过项目维护者的代理服务。直接浏览器调用要求提供商开放相应的 CORS 权限；连接失败时，应用会显示错误，不会改投其他模型服务。

## 解读内容

AI 解读是传统象征与自我反思材料，可能有误，不构成科学预测。请不要在问题中提交身份证号、联系方式或其他不必要的信息。
